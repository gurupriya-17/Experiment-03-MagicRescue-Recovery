# Experiment 3: Recover Deleted Files Using MagicRescue

## Aim
To recover deleted files from a storage device using MagicRescue.

## Tool Used
- MagicRescue

## Procedure
1. Open MagicRescue in a supported Linux environment.
2. Select the appropriate source device or disk image.
3. Choose the file type to be recovered.
4. Specify a separate output directory for recovered files.
5. Start the recovery process.
6. Check the output directory for recovered files.
